WanderTable

High-performance grid/spreadsheet library for the web. Zero dependencies, TypeScript, DOM-virtualized.

47 tests passing ~110 KB ESM ~9 KB CSS
RenderingDOM virtualized + CSS contain. Only visible cells exist (~750 nodes max).
Cell contentReal HTML. Any element, CSS, hover, transitions.
Data modelSparse Map. Only cells with data consume memory.
FormatsESM, CJS, UMD, IIFE (standalone), TypeScript declarations

Installation

npm / yarn / pnpm

npm install wandertable

CDN (standalone)

<!-- CSS -->
<link rel="stylesheet" href="https://unpkg.com/wandertable/dist/style.css">

<!-- JS (exposes window.WanderTable) -->
<script src="https://unpkg.com/wandertable/dist/wandertable.global.js"></script>

Quick Start

import { WanderTable } from 'wandertable';

const table = new WanderTable(document.getElementById('grid'), {
  rowCount: 1000,
  colCount: 26,
  data: [
    { row: 0, col: 0, data: { value: 'Hello' } },
    { row: 0, col: 1, data: { value: 42, type: 'number' } },
    { row: 1, col: 0, data: { value: true, type: 'checkbox' } },
    { row: 1, col: 1, data: { value: 'active', type: 'badge' } },
  ],
});

Live Demo

Click cells, arrow keys, type to edit, Ctrl+C/V, drag to select, right-click for menu.

Spreadsheet Mode

Each cell is independent. Data is scattered freely. Like Excel.

new WanderTable(el, {
  mode: 'spreadsheet',
  rowCount: 1000,
  colCount: 26,
});

// Each cell has its own type
table.setCell(0, 0, { value: 'text', type: 'text' });
table.setCell(1, 0, { value: 75, type: 'progress' });
table.setCell(2, 0, { value: true, type: 'checkbox' });

Table Mode

Column-driven. Rows replicate the column structure. Like a data table.

new WanderTable(el, {
  mode: 'table',
  columns: [
    { key: 'name', label: 'Name', width: 180 },
    { key: 'status', label: 'Status', type: 'badge' },
  ],
  tableData: [
    { name: 'Alice', status: 'active' },
    { name: 'Bob', status: 'pending' },
  ],
});

Layout Modes

ModeBehavior
scroll (default)Fixed height, internal scroll, virtualized. Best for large datasets.
autoGrid grows with content. Scroll on the page. No virtualization.
new WanderTable(el, { layout: 'auto', autoRowHeight: true });

Infinite Mode

Grid auto-expands when navigating or scrolling beyond current bounds.

new WanderTable(el, { infinite: true, rowCount: 50, colCount: 26 });

Renderers

Custom Renderer

table.registerRenderer('user-card', {
  render(cell, data, state) {
    const user = data?.value;
    cell.innerHTML = `<div class="card">
      <img src="${user.avatar}" />
      <span>${user.name}</span>
    </div>`;
  }
});

Editors

Built-in: text, dropdown (async, searchable, multi-select), blank.

table.registerEditor('date-picker', () => ({
  createElement(container) { /* create DOM */ },
  open(value, bounds, cellData) { /* show editor */ },
  getValue() { /* return edited value */ },
  close() { /* cleanup */ },
}));

Selection

  • Click = single cell
  • Shift+Click = range
  • Ctrl+Click = multi-range
  • Drag = area select
  • Header click = full row/column
  • Corner = select all
table.getSelectionInfo();
// { focus, bounds, cellCount, isFullRow, isFullCol, isMultiCell, ... }

Clipboard

Ctrl+C/V/X. TSV format compatible with Excel/Sheets. Single-cell paste fills the entire selection.

Undo / Redo

table.undo();
table.redo();

// Sync with external database
table.on('command:execute', (e) => db.save(e.changes));
table.on('command:undo', (e) => db.save(e.changes));
table.on('command:redo', (e) => db.save(e.changes));

Sort & Filter

table.sort(1, 'asc');
table.setFilter(2, (row, data) => data.getCell(row, 2)?.value === 'active');

// Server-side: use callbacks
new WanderTable(el, {
  onSort: (col, dir, key) => { fetchSorted(key, dir); return true; },
  onFilter: (col, key, active) => { fetchFiltered(key); return true; },
});

Fill Handle

Drag the square at bottom-right of selection. Supports all directions including diagonal.

new WanderTable(el, {
  allowFillHandle: true,
  onFill: (source, fill, direction) => {
    // Return CellPatch[] for custom fill
    // Return true to cancel
    // Return void for default (repeat pattern)
  },
});

Column Reorder

new WanderTable(el, { allowColReorder: true });

Context Menu

table.contextMenuItems = [
  {
    label: 'Custom Action',
    visible: (ctx) => ctx.target === 'cell',
    disabled: (ctx) => ctx.readOnly,
    action: (ctx) => doSomething(ctx.row, ctx.col),
  },
];
// ctx: { target, row, col, selectedCount, isMultiSelect, isFullRow, isFullCol, readOnly, canUndo, canRedo }

Export

Loading State

table.setLoading(true);  // show spinner overlay
table.setLoading(false); // hide

Lazy Loading

new WanderTable(el, {
  onLoadMore: (direction) => {
    table.setLoading(true);
    fetchMore().then(rows => {
      table.applyPatch(rows);
      table.setLoading(false);
    });
  },
});
